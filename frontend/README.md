# XanhSM - GreenOps Transport Frontend

Hệ thống quản trị vận hành và ứng dụng tài xế cho GreenOps Transport.

## Kiến trúc

```text
Monorepo Turborepo
├── apps
│   ├── admin     # Hệ thống quản trị (desktop-first)
│   └── driver    # Ứng dụng tài xế (mobile-first)
└── packages
    ├── ui            # UI primitives (Button, Input, Table, ...)
    ├── api-client    # HTTP client abstraction
    ├── auth          # Authentication & authorization
    ├── design-tokens # CSS variables, theme tokens
    ├── shared-types  # TypeScript types & schemas
    ├── utils         # Utility functions (format, mask, cn)
    ├── eslint-config # Shared ESLint config
    ├── tailwind-config # Shared Tailwind config
    └── typescript-config # Shared TS config
```

## Dependency Flow

```text
app → routes → pages → modules → shared → packages
```

## Yêu cầu

- Node.js >= 20
- pnpm >= 9

## Cài đặt

```bash
pnpm install
```

## Chạy development

```bash
# Tất cả apps
pnpm dev

# Chỉ admin
pnpm dev:admin    # http://localhost:3001

# Chỉ driver
pnpm dev:driver   # http://localhost:3002
```

## Cấu trúc app

```
apps/admin/src
├── app           # Bootstrap (router, query, providers)
├── layouts       # Layout components
├── modules       # Business modules (feature-based)
├── pages         # Page composition
├── routes        # TanStack Router routes (file-based)
├── shared        # App-level shared code
└── main.tsx      # Entry point
```

## Thêm route

Tạo file trong `src/routes/` theo convention TanStack Router file-based routing:

```text
routes
├── __root.tsx
├── _auth.tsx
├── _auth/login.tsx
└── _authenticated/drivers/$driverId.tsx
```

Route file validation dùng Zod:

```ts
const searchSchema = z.object({
  page: z.coerce.number().int().positive().catch(1),
});
```

## Thêm module

```text
modules/revenue
├── api/          # Queries, mutations, query keys
├── components/   # Module-specific components
├── forms/        # TanStack Form + Zod schema
├── hooks/        # Business hooks
├── models/       # Internal types
├── table/        # Column definitions
└── index.ts      # Public API
```

## Thêm UI component

Component trong `packages/ui/src/components/<name>/`:

```text
button
├── button.tsx
├── button.test.tsx
└── index.ts
```

## Design System

Design tokens được định nghĩa trong `packages/design-tokens/src/theme.css` và được import vào global CSS của mỗi app.

- **Brand**: Cyan (#00AEEF), Teal (#00C7A5), Deep Teal (#007D73)
- **Surfaces**: Card (#1C2737), Input (#3A4352), Selected (#123B45)
- **Text**: Primary (#F8FAFC), Secondary (#B6C0CD), Tertiary (#8792A2)
- **Semantic**: Success (#22C55E), Warning (#F59E0B), Error (#F05252), Pending (#A78BFA)
